/pipeline-power-bi: messy files to Power BI

A 20-second social video showing the workflow of the pipeline-power-bi skill: profile the files, clean them table by table, design a star schema, hand off to pbip-layout, pbip-catalog and pbip-governance, and how long a run takes. Each panel below is a key frame drawn by the same code the animation will use.

Facts and numbers I assumed

  • Run time: ≈ 8 min (fast), 10–12 min (quick), 20–30 min (full) come from the README's own estimate table. The video leaves out the extra 10–20 min for a first-time install and ≈ 5 min for the refresh and checks.dax in Power BI Desktop. The hero number is the fast run.
  • Table rows are real rows from demo/orders.csv. The cleaned values are shown in an en-US format (2025-01-03, 1,234.50). In a real run the display depends on the culture you pick in step 3.
  • Cleaning steps use the real fix codes from fix-catalog.md (F08, F11, F09, F12, F04). The order they switch on in is chosen for the story. The skill proposes them table by table.
  • Star schema: a Sales fact with Customer, Date and Channel dimensions is illustrative. Channel stands for the demo's 10/20/30 code column (F28). Your real model can differ.
  • Stage rail “Profile · Clean · Model · Extras” compresses the skill's steps 2–6 into 4 labels.
  • Hand-over shows 3 of the outputs (the PBIP project, overview.html and checks.dax). The real hand-over also lists the cleaning log, expected values, model health and more.
  • Title “Messy files to Power BI” and takeaway “Messy files → clean report” are my wording. Tell me if you want different copy.
